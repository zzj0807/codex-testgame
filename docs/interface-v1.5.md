# v1.5：界面与操作体验

v1.5 基于 v1.4.1。`dist/ai.js` 与 `dist/cortana-v1.4.1/ai.js` 逐字节一致，规则、回合开始锁牌、确定斩杀、残局搜索和亮牌后学习均保持原样。

## 界面

- 顶部提供「规则」「记牌器」「重开」，历史入口收在页脚。
- 规则使用可关闭的原生模态面板，支持 Escape、焦点返回和面板内滚动。关闭面板保持选牌与技能状态。
- 主画面保留选牌提示、技能状态、验牌区和回合结果。
- 血量显示为剩余数量的 SVG 爱心加数字；零血显示 `0/3`，血量容器保持宽度。

## 记牌器

从固定初始牌组和已公开历史计算，不读取 C 的当前锁牌计划。

- 普通回合：C 打出的牌数量减一。
- 交换回合：C 打出的牌数量减一，玩家交给 C 的牌数量加一；总张数不变。
- 翻牌前不更新历史或统计；包含本轮已选但尚未亮出的牌，不提示哪张已选。
- 数量为零仍保留点数，标记 `× 0`。重开恢复初始分布。

## 开牌与结算

`select → animating → reveal / over`。

1. 确认时记录本轮的牌值和技能快照，锁定选牌、技能及重复确认。
2. 双方匿名牌背移入验牌区约 320 毫秒。
3. 同步翻面约 330 毫秒，短暂停留 130 毫秒。
4. 普通回合显示大小比较与扣血，受损爱心淡出约 180 毫秒；交换回合显示换牌，增加约 280 毫秒的回手动画。
5. 完成真实结算后统一更新血量、手牌、记牌器和历史，再允许下一回合。终局也先完成本轮翻牌。

C 的动画源位置固定使用匿名牌背，不以实际选牌索引定位，避免位置泄露。动画副本不参与对局状态。

重开使旧动画失效，旧回调不能影响新局。滚动、旋转/调整窗口、切后台或切换减少动态效果时，取消视觉过渡并安全完成当前结算。减少动态效果或缺少 Web Animations API 时直接显示结果。动画结束、取消和超时均有退出路径，不依赖单个 `animationend` 事件。

`play_card` 工具等待结算完成后返回本轮结果；动画中重开时返回取消错误。

## 验证

已在开发环境执行：

- v1.0～v1.4 的现有规则/决策测试，以及指向独立存档的 v1.4.1 回归测试。
- v1.4.1 的 20 类直接斩杀、8 个可达场景、158 条分支和 9,000 个小残局检查。
- `tests/interface-v1.5.test.cjs`：确认 AI 文件逐字节一致；80 局、410 回合与 v1.4.1 的完整状态（含锁牌、学习权重、手牌、血量和终局）一致。
- 延迟结算、重复操作锁定、重开取消、工具等待/取消、动画失败退路。
- `tests/browser-v1.5.test.cjs`：Edge/Chromium 实际浏览器中的移牌翻牌、翻牌前信息隔离、规则与记牌面板、焦点返回、普通/交换/双倍/抵消/归零/第九回合。
- 验证 320、390、768、1440 像素视口无横向溢出，并检查手机触摸模拟、SVG 血量、窗口变化、减少动态效果与缺少动画 API 的退路。
- 截图人工检查桌面、手机布局和两个面板；无浏览器页面异常。

手机覆盖为浏览器模拟，未在实体 iPhone 或 Android 设备上测试；未声称复现旧版爱心不变灰的具体原因。新版通过按实际血量绘制 SVG 图标消除了对字符变灰的依赖。

## 版本与发布

- 最新入口：`dist/index.html`。
- v1.4.1 存档：`dist/cortana-v1.4.1/`，其 AI、游戏和样式保持原版，HTML 仅修正独立入口的相对导航。
- 更早存档继续保留，未删除文件或目录。
- `main` 保存源码、文档和测试；`gh-pages` 保存完整的 `dist` 静态目录。
- 样式和界面脚本附有 v1.5 资源版本参数，AI 仍使用 v1.4.1。
