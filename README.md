# 八牌对决 · Cortana 对战版

**八张手牌、三点血量。读懂 C 的技能提示，选择出牌或移花接木。**

### [▶ 最新版：Cortana 对战](https://zzj0807.github.io/codex-testgame/)

无需注册、登录、下载或填写 API Key，手机和电脑浏览器均可游玩。

## 这一版更新了什么？

- 对手改名为 **Cortana（简称 C）**，头像显示 C，移除了对手栏的「随机出牌」字样。
- 选牌阶段，C 头像下的 **「已选牌」小框亮起**；回合结算后变为空心。
- C 新增每局一次的 **伤害 ×2** 技能，发动回合的选牌阶段会提前亮出状态框。
- 使用移花接木时，C 按专门的加权规则出牌；同时可以抵消 C 当回合的翻倍技能。
- 经典版及移花接木初版独立保留，新版标签为 `v1.2.0-cortana`。

## 怎么玩

1. 在手牌中点击一张卡牌，确认前可以改选。
2. 查看 C 头像下的提示。如果「伤害 ×2」亮起，这回合的落败方会扣 2 点血。
3. 可以点击「移花接木」开启技能，再次点击可取消；确认出牌后不能反悔。
4. 点击「确认出牌」，双方同时亮牌并结算。
5. 点击「下一回合」继续，或点击「重新开始」重开一局。

双方起始血量均为 **3 点**，各有 **8 张牌**：

| 点数 | 数量 |
| --- | --- |
| 1 | 3 张 |
| 1.5 | 1 张 |
| 2 | 2 张 |
| 2.5 | 1 张 |
| 3 | 1 张 |

普通回合点数较小者扣 **1 点血**，相同则均不扣血。普通出牌使用后弃置。血量归零立即落败；双方手牌用完时，剩余血量较多者获胜，相同则平局。血量最低显示 0，不会出现负数。

## 玩家技能：移花接木

- **每局一次**，必须在确认出牌前开启；确认前可以取消，确认时消耗。
- 本回合双方亮牌后 **不扣血**，交换打出的卡牌并拿回手中，下回合可继续使用。
- 例如：你出 1，C 出 3。交换后你拿回 3，C 拿回 1，双方血量不变。
- 交换回合不减少手牌，因此一局最多可进行 9 回合。
- 重开新局后恢复技能次数。

## C 的技能：伤害 ×2

- 开局从 **第 1～8 回合**中等概率选一个发动回合，未来回合编号不会提前显示。
- 到达该回合，**选牌阶段**就亮起「伤害 ×2」框，让玩家先看到再决策。
- 翻倍只作用于**发动技能的这一回合**：落败方扣 2 血，无论落败的是玩家还是 C；平局仍不扣血。
- 如果玩家同回合开启移花接木，正常交换卡牌、不扣血，**C 的技能被抵消，但仍消耗次数**。
- 平局也消耗 C 的技能；C 不会再次发动。若游戏在预定回合之前结束，本局不会再补发技能。

## 移花接木时，C 怎样选牌？

初始完整手牌下：

| 卡牌 | 概率 |
| --- | --- |
| 1 点（三张合计） | 25% |
| 1.5 点 | 25% |
| 第一张 2 点 | 12.5% |
| 第二张 2 点 | 12.5% |
| 2.5 点 | 12.5% |
| 3 点 | 12.5% |

缺牌时只从**仍在手中的牌**选择：1 点组、1.5 点组存在时分别保留 0.25 权重，组内均分；每张其他牌保留 0.125 权重，最后按现有总权重归一化。不会抽到已经弃置的牌。

普通回合仍在剩余手牌中均匀选择。C 在回合开始就确定普通出牌与换牌条件下的方案，不读取玩家所选点数；反复开关技能或改选手牌不会刷新 C 的随机结果。

## 账号与 API

游戏是纯 HTML、CSS、JavaScript 静态网页，逻辑在浏览器本地运行，**不调用付费 API，不需要任何密钥**。

`.openai/hosting.json` 只保存另一个托管站点的项目标识和静态目录，不是 API Key，也不是 GitHub Pages 游戏运行依赖。

## 下载后离线玩

在仓库页面点击 **Code → Download ZIP**，解压后用浏览器打开：

- 最新版：`dist/index.html`
- 移花接木初版：`dist/swap-v1/index.html`
- 经典版：`dist/classic/index.html`

无需安装依赖或启动后端服务。

## 开发与验证

- `main`：完整源码、说明与测试。
- `gh-pages`：只包含网页文件，GitHub Pages 从分支根目录发布。
- `dist/game.js`：Cortana 对战版的规则和页面交互。
- `tests/game.test.cjs`：两个旧版的回归测试。
- `tests/cortana.test.cjs`：概率、选牌锁定、状态框、双倍伤害、抵消、次数限制和对局结束测试。

安装 Node.js 后运行：

```sh
node tests/game.test.cjs
node tests/cortana.test.cjs
```

修改游戏并提交后，将 `dist` 发布到 `gh-pages` 才会更新线上游戏；只修改 README 不需要重新发布网页：

```sh
git push origin HEAD:main
git subtree push --prefix=dist origin gh-pages
```
