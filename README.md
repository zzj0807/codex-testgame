# 八牌对决

无需账号、无需后端的浏览器卡牌游戏。直接打开 `dist/index.html` 即可游玩，也可把 `dist` 部署到任意静态网站托管平台。

## 版本

- 技能版：`dist/index.html`。
- 经典版：`dist/classic/index.html`，保留原始玩法和界面。
- `v1.0.0-classic` 标签保存最初版本。

## 规则

双方初始手牌：1 点 × 3、1.5 点 × 1、2 点 × 2、2.5 点 × 1、3 点 × 1；初始血量均为 3。
每回合选择一张牌，确认后与电脑随机选择的剩余手牌同时亮出。点数较小者扣 1 血，平局不扣血。普通回合的牌使用后弃置。血量为 0 立即落败；无牌时比较血量，同血则平局。

技能版增加「移花接木」：玩家每局一次，必须在确认出牌前开启，可在确认前取消。该回合亮牌后不扣血，两张牌交换并回到双方手牌，下回合可使用。技能在确认出牌时消耗；重开新局恢复。电脑仍随机出牌且没有技能。交换回合不减少手牌，最多可进行 9 回合。

## 开发与验证

无需安装依赖。执行 `node tests/game.test.cjs` 检查核心规则和技能边界。

`dist` 是完整独立静态站点，不依赖 ChatGPT 登录或 API；`.openai/hosting.json` 仅用于现有 Sites 托管，不是游戏运行依赖。
