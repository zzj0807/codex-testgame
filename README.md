# 八牌对决

**八张手牌、三点血量。与随机出牌的电脑，同时亮牌对决。**

## 🎮 点击这里直接玩

### [▶ 开始游戏：技能版](https://zzj0807.github.io/codex-testgame/)

### [🃏 开始游戏：经典版](https://zzj0807.github.io/codex-testgame/classic/)

**不需要注册、登录、下载或填写 API Key。** 手机和电脑浏览器均可直接游玩。

> 当前仓库名为 `codex-testgame`。旧的 `/codex-/` 游戏地址已停用，请收藏上面的新地址。

## 怎么玩

1. 点击手中的一张卡牌；确认前可以换牌。
2. 点击「确认出牌」，电脑从自己的剩余手牌中随机出一张，双方同时亮牌。
3. 点数较小的一方扣 **1 点血**；点数相同，双方不扣血。
4. 点击「下一回合」继续。血量归零立即落败；双方手牌用完时，血量较多者获胜，相同则平局。
5. 点击「重新开始」可重开一局。

双方起始血量均为 **3 点**，各持有以下 **8 张牌**：

| 点数 | 数量 |
| --- | --- |
| 1 | 3 张 |
| 1.5 | 1 张 |
| 2 | 2 张 |
| 2.5 | 1 张 |
| 3 | 1 张 |

## 两个版本有什么区别？

| 版本 | 玩法 | 保留版本标签 |
| --- | --- | --- |
| 经典版 | 普通出牌后弃置，没有技能 | `v1.0.0-classic` |
| 技能版 | 在经典规则上增加一次「移花接木」 | `v1.1.0-swap` |

### 技能「移花接木」

- 玩家**每局只能使用一次**，在确认出牌前点击技能按钮开启，也可以在确认前取消。
- 开启后，本回合双方亮牌，**不扣血**，直接交换各自打出的牌。
- 换来的牌回到手中，**下一回合可继续使用**。
- 例如：你出 1，电脑出 3。使用技能后，你拿回 3，电脑拿回 1，双方血量不变。
- 确认出牌时消耗技能；重新开始一局后恢复。电脑没有技能，仍随机出牌。
- 交换回合不减少手牌数量，所以技能版最多进行 9 回合。

## 账号与 API

游戏是纯 HTML、CSS、JavaScript 静态网页，逻辑全部在浏览器本地运行，**不调用付费 API，也不需要任何密钥**。

`.openai/hosting.json` 只保存另一个托管站点的项目标识与静态目录，不是 API Key，不参与 GitHub Pages 上的游戏运行。

## 下载后离线玩

在仓库页面点击 **Code → Download ZIP**，解压后：

- 技能版：用浏览器打开 `dist/index.html`。
- 经典版：用浏览器打开 `dist/classic/index.html`。

不需要安装依赖或启动后端服务。

## 给开发者

- `main`：完整源码、说明与测试。
- `gh-pages`：仅包含发布用网页文件，GitHub Pages 从这个分支的根目录发布。
- `dist/`：技能版页面；`dist/classic/`：保留的经典版页面。
- `tests/game.test.cjs`：普通出牌、换牌、次数限制、取消、重开及结束条件测试。

安装 Node.js 后，在仓库根目录运行：

```sh
node tests/game.test.cjs
```

修改游戏后，需要把 `dist` 同步到 `gh-pages` 才会更新线上游戏；只更新 README 不需要重新发布网页：

```sh
git push origin HEAD:main
git subtree push --prefix=dist origin gh-pages
```

## 为什么改仓库名后有些旧链接还能打开？

- **仓库地址**：GitHub 会把旧仓库链接重定向到新仓库。
- **游戏地址**：GitHub Pages 项目网址包含仓库名，应使用本 README 顶部的新地址；不要依赖旧地址持续有效。
- **页面标题**：「八牌对决」由网页代码决定，改仓库名不会自动改游戏名称。
- **原来的 `chatgpt.site` 网站**：是单独部署的站点，GitHub 仓库改名不会改变它的地址。

参考：[GitHub 官方仓库改名说明](https://docs.github.com/en/repositories/creating-and-managing-repositories/renaming-a-repository)。
